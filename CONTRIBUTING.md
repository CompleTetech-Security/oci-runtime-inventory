# Contributing

Read AGENTS.md, README.md and SECURITY.md. Keep this an optional standalone
Python 3.10+ standard-library metadata tool. Never execute or extract images,
follow archive links, infer versions from tags/filenames, or collect configuration
secrets. Use only synthetic archives in tests. Preserve bounds, whiteouts,
uncertainty, protected output, interruption handling and consumer schemas.

Run `python -m unittest -v`, `python oci_runtime_inventory.py --help` and
`git diff --check`. GitHub Copilot review and exact-head hosted CI precede merge.
